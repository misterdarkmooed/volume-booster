# Volume Booster para Windows

Aplicación sencilla para controlar el volumen de Windows.

> **Importante:** este programa no puede saltarse las restricciones del ordenador del instituto ni superar físicamente el límite del dispositivo de audio. Si el equipo está administrado, no intentes desactivar sus controles.

## Cómo abrirlo

1. Descarga el repositorio como ZIP desde **Code → Download ZIP**.
2. Extrae el ZIP.
3. Haz doble clic en `run.bat`.
4. Si Windows pregunta por Python, necesitarás Python instalado y permitido por el administrador.

También puedes ejecutar:

```text
python volume_booster.py
```

## Uso responsable

Subir demasiado el volumen puede dañar tu audición o los altavoces. Empieza bajo y no uses auriculares a volumen alto durante mucho tiempo.
